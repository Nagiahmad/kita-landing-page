# Ikuyo Kita Landing Page

## Overview

A simple landing page project created to practice writing clean, organized, and readable HTML and CSS code.

The main goal of this project is to improve my understanding of website structure and make the code easier for other developers to read and maintain.

## Features

* View Ikuyo Kita's profile and basic information
* Responsive layout for different screen sizes

## Tech Stack

* HTML
* CSS
* JavaScript

## How It Works

The project separates the website structure, styling, and responsive design into different files:

* `index.html` — The main structure of the website.
* `style.css` — The main styling for desktop and larger screens.
* `responsive.css` — Contains responsive styles for mobile devices and smaller screens.
* `base.css` — Contains general styles shared across different screen sizes.
* `main.js` — Handles the website's interactive functionality.
